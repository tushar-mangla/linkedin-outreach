# Feature 3: AI-Personalized Messaging
**Release:** `v0.3-messaging`

## Intention
Generate concise, evidence-based connection notes and message packages that a human can review, edit, approve, and export without sending them.

## User Outcome
A user can select verified prospect evidence, generate a connection note, first DM, and configurable follow-ups, inspect the critique and provenance, approve or edit versions, and export the approved package.

## Scope
- Evidence items with source, timestamp, value, confidence, and permitted usage.
- Two-pass generation: analysis/draft followed by critique/revision.
- Connection note, first DM, at least five configurable follow-ups, optional close message, and reply suggestions.
- Account/channel capability and length limits.
- Versioned prompts, schemas, models, drafts, critiques, edits, approvals, and final content.
- Quality checks for factual grounding, relevance, brevity, tone, repetition, unsupported claims, and progression.
- Reply classification: positive, information request, objection, not interested, wrong person, out of office, later, opt-out, or unclear.

## Domain States
Messages have independent draft, approval, and delivery states. Reply classification must stop future outbound recommendations before any reply is suggested or sent.

## Contracts
Messaging depends on `AIProvider.generateStructured()` and never calls Gemini directly. Every generated claim must reference permitted evidence. Account capability limits are configuration, not hard-coded assumptions.

## Persistence and Migrations
Add tenant-scoped evidence, message packages, message versions, critiques, approvals, reply records, and classifications through reviewed Drizzle migrations. Preserve original, edited, and final content plus provider metadata.

## Implementation Boundaries
This release generates and exports content only. It does not send messages, enroll campaigns, synchronize a live inbox, or use Playwright.

## Tests
Test evidence selection, prompt construction, fake-provider responses, malformed output, unsupported claims, length limits, duplicate follow-ups, versioning, approval workflow, reply-stop behavior, and tenant isolation.

## Offline Demonstration
Use five synthetic prospects with fixture evidence, generate packages through a fake provider, show critique and provenance, edit and approve selected messages, classify a sample reply, and export only approved content.

## Human Approval
The project lead approves the evidence policy, prompt and schema versions, message limits, quality rules, approval workflow, and offline demonstration.

## Release Gate
Feature 3 is complete only when approved, evidence-backed message packages with configurable follow-ups are generated, versioned, validated, and exportable without external sending. The release tag is `v0.3-messaging`.
